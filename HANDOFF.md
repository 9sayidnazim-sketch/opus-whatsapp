## 2. Browser Web Push Notifications Architecture
Engineered per the user request for native browser push notification capability:
- **Service Worker (`public/sw.js`):**
  - Handles `push` events with JSON/text payload parsing, custom icons (`/favicon.svg`), vibration pattern `[100, 50, 100]`, and action buttons ("Open Ledger", "Dismiss").
  - Handles `notificationclick` events with multi-window routing and tab focusing.
- **Notification Utility Module (`src/utils/notifications.js`):**
  - `isNotificationSupported()`: Browser feature detection.
  - `getNotificationPermission()`: State detection (`default` | `granted` | `denied`).
  - `registerServiceWorker()`: Auto-registers `/sw.js` with root scope.
  - `requestNotificationPermission()`: Interactive prompt handler.
  - `showBrowserNotification()`: Dual-path fallback supporting Service Worker notifications with Window Notification API fallback.
  - `sendTestPushNotification()`: Interactive test trigger with custom badge.
  - `checkAndTriggerDueAlerts()`: Automated evaluation engine that triggers alerts for:
    1. **Upcoming Bills:** Pending bills due in $\le 3$ days (or custom threshold).
    2. **Budget Threshold Warnings:** Budgets that have reached or exceeded the set threshold ($\ge 80\%$).
- **UI Integration:**
  - **Dashboard (`src/pages/Dashboard.jsx`):** Automatically evaluates due bills and budget limits on load; displays an interactive 1-click "Enable Alerts" card in `NotificationsBanner.jsx` when permission is unprompted.
  - **Settings (`src/pages/Settings.jsx`):** Dedicated "Browser Push Notifications" card with live permission status pill, one-click enablement, and a "Send Test Push" button.
  - **Header & Mobile Header (`src/Layout.jsx`):** Quick notification bell button with active status indicator.

## 4. SimpleWebAuthn Biometrics Architecture
Engineered per the user request using `@simplewebauthn/browser` and `@simplewebauthn/server`:
- **Hardware Integration:**
  - Automatic detection of biometric support via `checkBiometricsSupport()` (`browserSupportsWebAuthn` and `platformAuthenticatorIsAvailable`).
  - Native hardware enclave integration for Face ID, Touch ID, Windows Hello, and Android Biometrics.
- **Registration Flow:**
  - `POST /api/webauthn/registration-options`: Generates challenge, RP details (`Fuloozi Household Ledger`), and cryptographic public key parameters via `@simplewebauthn/server`.
  - Client prompts native Touch ID / Face ID sheet via `startRegistration({ optionsJSON })`.
  - `POST /api/webauthn/verify-registration`: Validates attestation response and stores credential ID, public key, counter, and friendly device name.
- **Authentication Flow:**
  - One-tap "Sign in with Face ID / Touch ID" on the Sign In screen.
  - Native biometric prompt signs the server challenge.
  - On verification, creates authenticated session and opens ledger instantly without typing.
  - Seamless fallback to 4-digit MPIN always available.
- **Settings Management:**
  - Device Passkeys card in Settings with enrollment status, hardware badges, and credential deletion.
